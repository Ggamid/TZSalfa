# TZ — Doctors App (SwiftUI)

Тестовое задание: список врачей, карточка врача и экран стоимости услуг.  
Данные читаются **из локального JSON** (Bundle), без сетевых запросов.

---

## ✨ Возможности
- Список врачей с фото, рейтингом, стажем и ценой
- Поиск по ФИО и специализации
- Фильтры по цене / стажу / рейтингу (возр./убыв.)
- Детальная карточка врача
- Экран стоимости услуг
- Кастомный таббар и навбар
- Локальный JSON (`Resources/Data/doctor.json`)

---

## 🛠️ Стек
- **SwiftUI**
- **MVVM**
- **JSON Decoder** (Bundle)
- Архитектурные слои: Models / Services / Features / UI / PreviewContent
